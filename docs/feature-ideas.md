# 추가할 기능 검토

- 검토일: 2026년 11월 13일
- 기준 버전: 0.11.0 (`43ba8e8`)
- 진행: 1순위의 "세션 줄에 지금 하는 일 표시"는 구현했습니다(2026년 11월 13일). 나머지는 아직 제안 상태입니다.
- 덧붙임(2026년 11월 14일): 아래 "권하지 않는 것"의 "사이드바타입 더 늘리기"와 달리, 사용자의 요청으로 할 일·명령·표 항목과 북마크(Ctrl+숫자로 바로 가기)를 더했습니다. 새 종류는 화면 파일을 따로 두었고(`ui/todo.js`, `ui/run.js`, `ui/table.js`), `ui/main.js`에는 등록·도구·복원을 잇는 부분만 붙었습니다.

## 진단

사이드바타입은 9가지(Claude·터미널 세션, 메모, HTTP, 사이트, 이미지, 마인드맵, 문서, 그룹 등)로 이미 넓습니다.
그래서 종류를 더 늘리기보다는 **세션 여러 개를 동시에 돌리면서 사람이 손을 대야 하는 순간**을 줄이는 쪽에 효과가 큰 기능이 남아 있습니다.

## 1순위: 바로 체감되는 것

### 1. 승인을 그 자리에서 처리

- 지금은 `Notification` 훅으로 "승인 대기"만 알 수 있어서, 결국 그 세션으로 가서 터미널에서 답해야 합니다.
- Claude Code의 `PermissionRequest` 훅을 쓰면 알림이나 사이드바 줄에 `Bash · cargo test --workspace`처럼 무엇을 승인하는지 보여 주고, [허용]/[거절]을 바로 누를 수 있습니다.
- 전달 프로그램은 답을 기다리다가 시간이 지나면 아무 답도 하지 않고 물러납니다. 그러면 터미널의 원래 승인 창이 그대로 남습니다.
- 답은 본창 화면에서만 받게 해서 지금의 보안 규칙을 지킵니다(사이트 항목의 웹 페이지는 부를 수 없게).
- 만들기 전에, 쓰는 Claude Code 버전에서 이 훅의 입력·출력 형식을 먼저 확인해야 합니다.

### 2. 세션 줄에 "지금 하는 일" 표시

- `PreToolUse` 훅은 지금 `Write`에만 걸려 있습니다(`crates/cypher-app/src/claude.rs`의 `settings_json`).
- 이것을 모든 도구로 넓히면 줄마다 `Edit · main.js`, `Bash · cargo build`처럼 지금 하는 일이 보입니다.
- 오래 도는 명령이나 같은 일을 맴도는 세션도 접어 둔 채 알아챌 수 있습니다.
- 대신 도구를 쓸 때마다 전달 프로그램이 한 번씩 떠서 수십 ms가 듭니다. 그래서 설정으로 켜고 끄게 하는 편이 좋습니다.
- 1번과 같은 훅·전달 프로그램 경로를 쓰니 함께 만들면 품이 줄어듭니다.

### 3. 한도가 풀리면 이어서 보내기

- 5시간 한도가 풀리는 시각(`resets_at`)은 이미 받아서 창 아래에 표시하고 있습니다(`ui/main.js`의 한도 표시 부분).
- 한도에 걸려 멈춘 세션에 "풀리면 '계속' 보내기"를 걸어 두면 밤사이나 자리를 비운 동안에도 이어서 돌아갑니다.
- 실행 중에 미리 입력해 두는 것은 Claude Code가 이미 지원하므로, 이 기능의 핵심은 "시각에 맞춰 보내기"입니다.

## 2순위: 쓸모가 분명한 것

### 4. 지난 대화 찾기

- 지금 찾기(Ctrl+Shift+F)는 화면 안에서만 되고, 닫은 항목 다시 열기는 Cypher에서 연 것을 30일 동안만 기억합니다.
- `~/.claude/projects/*/*.jsonl` 전체에서 글자로 찾아 결과를 누르면 그 대화를 이어서 엽니다. 세션 복원에 쓰는 이어 열기를 그대로 쓰면 됩니다.
- "지난주에 그 버그를 어떻게 고쳤더라" 같은 경우에 씁니다.

### 5. 작업 표시줄·트레이에 대기 표시

- 지금 창 밖으로 알리는 방법은 Windows 알림과 `request_user_attention`(`crates/cypher-app/src/commands.rs`)뿐입니다.
- 작업 표시줄 아이콘에 대기 중인 세션 수를 겹쳐 보이고, 창이 뒤에 있어도 전역 단축키로 다음 대기 세션으로 바로 가게 합니다(지금의 Ctrl+Shift+N은 창 안에서만 동작).
- 품이 적게 듭니다.

### 6. 그룹별 비용·작업 시간 합계

- 비용과 작업 시간은 세션마다 이미 모으고 있고, 그룹이 곧 업무 하나입니다.
- 이것을 합쳐서 묶음 머리에 "이 업무 $12.40 · 3시간 20분"으로 보이고, 하루 단위 기록을 남깁니다.

## 3순위: 있는 기능을 조금 넓히는 것

### 7. 그룹 틀에 세션별 시작 프롬프트

- 지금 틀은 세션을 빈 상태로 시작합니다(대화는 담지 않고 새로 시작).
- "펼치면 각 세션이 이 지시로 시작"까지 담을 수 있게 합니다.

### 8. HTTP 환경 파일

- IntelliJ `.http` 형식을 따르는데 `http-client.env.json`·`http-client.private.env.json`(개발·운영 서버 전환)은 아직 없습니다.
- 지금은 파일 안의 `@변수`와 `{{$env 이름}}`으로만 값을 바꿀 수 있습니다.

### 9. 사용자가 직접 하는 세션 간 넘기기

- 도구로 세션끼리 다루지 못하게 한 원칙은 그대로 둡니다.
- 다만 사용자가 "이 세션의 마지막 응답을 저 세션 입력창에 넣기"를 누르는 기능은 변경 내용에서 "줄을 골라 지시하기"와 같은 성격이라 원칙과 부딪히지 않습니다.
